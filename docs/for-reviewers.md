# BI Academy — материалы для комиссии

## Как соблюдено задание

| Требование | Реализация |
|---|---|
| Персональный герой | После регистрации сотрудник обязательно отвечает на 7 вопросов анкеты и получает созданного по ним аватара. Аватар помогает подобрать рабочие ситуации и не влияет на оценки. |
| Тест из 15 вопросов | ИИ выбирает первые 10 из базы готовых строительных ситуаций; ещё 5 открытых вопросов задаются последовательно, каждый с учётом всех предыдущих ответов. |
| Четыре качества в процентах | Критическое мышление, уверенность в себе, дисциплина и вовлечённость показаны отдельными шкалами с основаниями оценки. |
| Профессиональные навыки | Отдельный результат содержит 3–5 навыков по должности, проценты, цитаты, сильные стороны и следующие шаги. Обе рубрики оцениваются одним запросом после 15 ответов. |
| Рекомендации | Персональный план развития на 30 дней и темы для изучения в BuildEX/BIU при низких показателях. Подключения к этим системам нет. |
| Доступ руководителя | Руководитель видит результаты сотрудника и его аватар после согласия сотрудника на передачу результата команде. |

## Сценарий показа

1. Зарегистрировать сотрудника и ответить на семь вопросов для героя.
2. Указать должность и показать первые десять вопросов, выбранных из банка. Тексты и баллы вариантов уже записаны в SQLite.
3. Ответить на пять открытых вопросов и показать, что каждый следующий учитывает сохранённые ответы.
4. Открыть два результата: четыре качества с радаром и отдельные профессиональные навыки. Показать дословные основания, области роста и план на 30 дней.
5. Открыть рекомендованную тему BuildEX/BIU. Это направление для изучения, а не назначенный курс.
6. При наличии второй учётной записи показать согласие сотрудника и результат в кабинете руководителя.

## Архитектура и ограничения

React/TypeScript отвечает за интерфейс, Node/Express — за аккаунты и запросы, SQLite — за банк вопросов, черновики и результаты. Готовый банк содержит 300 ситуаций по 12 должностным группам; [формат и импорт](question-bank.md) позволяют расширять его. ИИ на старте возвращает только ID десяти готовых вопросов. Пять открытых вопросов создаются по одному. После завершения один структурированный ответ ИИ содержит обе рубрики, объяснения и рекомендации; сервер проверяет ID, уровни и точность цитат. Подробная [методика](methodology.md) фиксирует расчёт и ограничения.

Это прототип инструмента развития. Вопросы, проценты и рекомендации ещё нужно проверить в пилоте со строительными специалистами; они не подтверждают квалификацию и не заменяют оценку руководителя. Для реального прохождения требуется серверный ключ OpenAI API.
