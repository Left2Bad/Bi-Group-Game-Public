# Показ BI Academy

## Подготовка

Запустить `npm ci`, `npm run build`, `npm start`; открыть `http://localhost:3000`. Для полного прохождения нужен серверный `OPENAI_API_KEY`. Без ключа можно показать регистрацию, обязательный аватар, стартовый банк и сохранённые результаты, но новое прохождение не начнётся. Для руководителя подготовить отдельную учётную запись и согласие сотрудника.

## Что показать

1. **Создание героя.** Зарегистрировать сотрудника. Сайт сразу ведёт к семи вопросам: вселенная, пол, стиль, роль, действие в сложной ситуации, мотивация и суперсила. Показать, что ответ обязателен на каждом шаге. Аватар отражает анкету и не даёт баллы.
2. **Первые десять ситуаций.** Указать должность. ИИ получает краткое описание готовых вопросов и возвращает только ID десяти наиболее подходящих из базы. Текст вариантов и баллы не генерируются при старте. Показать сохранение ответа после обновления страницы.
3. **Пять открытых ответов.** Каждый вопрос создаётся после предыдущего ответа и опирается на все сохранённые ответы. Описать профессиональное решение, его причину и способ проверить результат.
4. **Два результата.** После 15 ответов один запрос ИИ формирует четыре качества и отдельные профессиональные навыки. Открыть радар, проценты, сильные стороны, области роста и цитаты, на которых основан вывод.
5. **Развитие.** Показать план на 30 дней и предложенную тему BuildEX или BIU для слабого навыка. Это текстовая рекомендация: доступа к курсам, записи и отслеживания их прохождения нет.
6. **Руководитель.** После согласия сотрудника открыть его результат в команде. Руководитель видит обе рубрики и аватар сотрудника.

## Короткие ответы на вопросы

- **Как выбираются первые десять?** Из таблицы `question_bank`: сервер предварительно отбирает подходящие активные записи, ИИ возвращает десять ID, сервер проверяет уникальность и покрытие четырёх качеств. [Формат банка](question-bank.md).
- **Как получаются проценты?** Для каждого качества две трети даёт оценка выбранных вариантов, одну треть — поведенческая оценка всех 15 ответов. Профессиональные навыки имеют отдельные уровни 0–4, которые сервер переводит в проценты. [Методика](methodology.md).
- **Можно ли считать результат кадровой оценкой?** Нет. Это ориентир для развития; рубрику нужно проверить с профильными экспертами и откалибровать на реальных ответах.
- **Есть ли интеграция с BuildEX или BIU?** Нет. Сайт предлагает только темы для дальнейшего изучения.
- **Что сохраняется?** В SQLite хранятся аккаунт, снимок вопросов, ответы, результаты, история и отметки плана. Руководитель видит результат после согласия сотрудника.

Перед демонстрацией пройти полный сценарий на целевом сервере и проверить доступность модели через настроенный API-ключ.
